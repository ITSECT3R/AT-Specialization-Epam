What should be done

1. Install Jenkins locally

2. Create pipelines with 2 jobs where:

· The repo with tests will be cloned

· The 1-st job will run UI tests and 2-nd job will run API tests

3. Set up the trigger to perform test every 2 hours 

4. Demo it to your mentor

Assessment criteria (pass rate is 70%)

Here’s the list of actions which result in reduction of overall mark for a completed task:

1. Jenkins is not set up (-70%)

2. Jobs with tests are not set up (each job = - 20%)

3. The trigger isn’t set up (-10%)

4. Other trivial mistakes (-10%)
